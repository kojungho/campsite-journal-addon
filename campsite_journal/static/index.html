앱 설치·연결

안드로이드

  1. 아래 설치 파일을 다운로드합니다.
  2. 파일 앱에서 APK를 열고 설치합니다. 요청되면 이 출처의 앱 설치를 허용합니다.
  3. ‘캠핑장 기록’을 열고 아래에서 만든 기기 연결키를 붙여넣습니다.
  4. 설정에서 갤러리 또는 파일 앱을 선택합니다.
안드로이드 APK 다운로드

아이폰 / 아이패드

  1. 아래에서 아이폰 기기 연결을 만듭니다.
  2. 연결 주소를 Safari로 열어 연결합니다.
  3. 공유 → 홈 화면에 추가 → 웹앱으로 열기 → 추가를 누릅니다.
  4. 홈 화면의 ‘캠핑장 기록’ 아이콘으로 바로 접속합니다.

아이폰용은 홈 화면 웹앱입니다. App Store 배포 앱은 아닙니다. iOS 17.2 이상을 권장합니다.

기기 연결 관리

기기 연결키를 가진 기기만 기록에 접근합니다. 홈어시스턴트 로그인 정보는 앱에 저장하지 않습니다.

다른 홈어시스턴트에 연결 구성요소 설치

연결 ZIP을 /config/custom_components 아래에 풀고 configuration.yaml에 campsite_journal_bridge: 를 추가한 다음 설정을 검사하고 HA를 재시작합니다. 현재 서버에는 자동 설치됩니다.
