# 캠핑장 기록

Home Assistant에서 방문한 캠핑장을 남기고, 안드로이드 앱과 아이폰 홈 화면 웹앱에서도 같은 기록을 열어봅니다.

## Home Assistant 설치

1. 설정 → 앱(애드온) → 앱 스토어 → ⋮ → 저장소에 `https://github.com/kojungho/campsite-journal-addon` 추가.
2. **캠핑장 기록** 설치 → 시작 → **사이드바에 표시** 켜기.
3. 사이드바 **캠핑장 기록** 접속.

Home Assistant OS / Supervisor 필요. GitHub Actions에서 테스트 후 amd64 / aarch64 이미지를 빌드하여 GHCR에 배포합니다. HA에서는 이미 빌드한 이미지를 다운로드합니다.

## 기능

- 예약 플랫폼, 예약 링크 ↗, 캠핑장명, 위치, 지도 링크 ↗, 사이트명, 가격(원), 입실·퇴실·숙박일수, 메모.
- 목록 행을 눌러 상세정보 열기. 목록에서 숨긴 항목도 상세에는 유지.
- 사진 갤러리와 배치도 갤러리. ＋를 눌러 여러 장 첨부. 사진 클릭 시 확대, 사진 안 ×로 삭제.
- JPG, PNG, WebP, GIF, HEIC 지원. 방향 보정 후 최대 3200px JPG로 저장. 한 번에 64MB까지 첨부.
- 무료 주소 검색 / 지도 클릭 위치 선택. 상세 지도와 전체 방문 지도. 지도 링크를 붙여넣고 좌표도 등록해야 지도 핀이 표시됩니다.
- 지도 및 위치 검색은 인터넷 연결 필요. 위치 검색 버튼을 누르면 입력한 이름·주소를 Photon 위치 검색 서비스에 전달합니다.
- 설정: 항목 표시 ON/OFF, ☰ 핸들로 마우스·터치 드래그 순서 이동. 키보드 위/아래 방향키 지원.
- PC / 모바일 별도 열 너비(최소 20px), 글자 크기(최소 8px), 셀 여백(최소 2px). 모바일 기준 700px.
- 전체 기록·사진 ZIP 백업. 기기 연결키는 백업에서 제외.

데이터: `/data/campsite-journal/journal.sqlite3`, 사진: 같은 디렉터리의 `photos/`. 재시작·업데이트 후 유지되고 HA 앱 백업에 포함됩니다.

## 자체 앱 연결 구성요소 설치

1. 앱 설치·연결에서 연결 ZIP을 받습니다.
2. `/config/custom_components/campsite_journal_bridge/`에 `__init__.py`, `manifest.json`을 넣습니다.
3. configuration.yaml에 아래 항목 추가 → 설정 검사 → HA 재시작.

```yaml
campsite_journal_bridge:
```

4. 앱 설치·연결의 주소를 `https://ha.badara.co.kr/campsite-journal/`로 설정하고 자체 앱 연결을 허용합니다.

기본 내부 주소는 `http://e1946121-campsite-journal:8098`입니다. 저장소 URL이 달라지면 backend_url을 실제 앱 hostname에 맞추세요. 별도 인터넷 포트는 열지 않습니다. 연결 구성요소는 캠핑장 기록 경로만 전달하고, 기기 연결키가 있어야 기록에 접근할 수 있습니다. HA 비밀번호는 자체 앱에 저장되지 않습니다. HA에서 기기를 해제하면 접근이 차단됩니다.

## 안드로이드 설치

1. HA → 캠핑장 기록 → **앱 설치·연결 → 안드로이드 APK 다운로드**.
2. 파일 앱에서 APK 열기 → 설치. 요청되면 이 출처의 앱 설치 허용. Android 10 이상 지원.
3. HA에서 기기 이름·안드로이드 선택 → **기기 연결 만들기**.
4. 앱에 기기 연결키 붙여넣기 또는 연결 버튼/QR 사용.
5. 홈 화면 **캠핑장 기록** 아이콘으로 접속.
6. 앱 설정에서 갤러리 / 파일 앱 선택. 기기마다 따로 저장됩니다.

서명된 APK는 GitHub 릴리스에서도 제공합니다. 공개 APK에는 HA 로그인 정보나 기기 연결키가 없습니다. 연결키는 Android Keystore로 암호화됩니다. APK 서명키는 소스에 포함되지 않습니다.

## 아이폰 / 아이패드 설치

1. HA에서 아이폰용 기기 연결 생성.
2. 연결 주소를 **Safari**로 열어 연결.
3. **공유 → 홈 화면에 추가 → 웹앱으로 열기 → 추가**.
4. 홈 화면 **캠핑장 기록** 아이콘으로 접속. iOS 17.2 이상 권장.
5. 설정에서 파일 모드는 **파일 선택**, 갤러리 모드는 **사진 보관함** 선택. iOS의 선택 메뉴 표시는 운영체제에서 결정합니다.

아이폰용은 홈 화면 웹앱(PWA)입니다. App Store 네이티브 앱은 아니며 인터넷·HA 연결이 필요합니다. 인증이 풀리면 기기 연결키로 다시 연결하세요. HA 앱에서는 파일 선택 방식으로 첨부합니다.

## 개발과 배포

```sh
python3 -m venv .venv
.venv/bin/pip install -r campsite_journal/requirements.txt
JOURNAL_DATA=./.local-data JOURNAL_HOST=127.0.0.1 .venv/bin/python campsite_journal/app.py
.venv/bin/python -m unittest discover -s tests -v
```

로컬 화면: http://127.0.0.1:8099. 운영 컨테이너 8099는 Ingress 프록시만 허용, 8098은 기기 인증 필요. 기기 관리 API는 HA Ingress에서만 사용 가능합니다.

이미지 업데이트: config.yaml 버전을 올리고 main push → Actions 성공 → HA 스토어 업데이트 확인. 최초 GHCR 패키지는 Public인지 확인하세요.

APK 빌드: SDK build-tools 36.1.0 / android-36, JDK 필요. `ANDROID_SDK_ROOT`, `CAMP_APK_BUILD_DIR`(소스 외부), `CAMP_APK_KEYSTORE`(소스 외부), `CAMP_APK_STOREPASS` 환경변수 설정 후 `android/build-apk.sh`. 기존 키를 유지해야 앱을 덮어써 업데이트할 수 있습니다.

## 무료 주소 검색 및 지도 위치

1. 기록 추가/수정 → **주소 검색 (무료)** → 도로명·지번·건물명 검색 → 주소 선택.
2. 지도 위치 선택에서 후보 또는 지도 위의 정확한 위치를 누르고 **이 위치로 선택**.
3. 저장하면 전체 방문 지도에 표시됩니다. 주소만 필요하면 **주소만 사용**으로 닫고 저장할 수도 있습니다.

주소 검색은 카카오 우편번호 서비스이며 키 발급·결제가 필요 없습니다. 좌표 후보는 Photon의 무료 공개 서비스로 조회합니다. 후보의 정확도를 지도에서 확인하세요. 조회 실패/검색 결과 없음일 때도 지도에서 직접 위치를 선택할 수 있습니다. 위도·경도는 내부적으로 저장되며 직접 입력하지 않습니다. 예약/지도 링크는 연결 모양 아이콘으로 열립니다. 입실·퇴실 입력칸을 누르면 달력이 열리며 입실일 → 퇴실일 두 번 선택하면 자동 완료됩니다. 좌우 버튼으로 달 이동 가능합니다.

무료 위치 후보 서비스는 소량 이용을 전제로 하며 사용 가능 여부를 보장하지 않습니다. 앱은 자동완성·일괄 조회를 하지 않고 초당 최대 한 요청, 30일 결과 캐시로 사용량을 제한합니다. 주소 검색어는 카카오, 지도 위치 검색어는 Photon으로 전달됩니다. 지도 데이터 © OpenStreetMap. 공식 안내: https://postcode.map.kakao.com/guide / https://github.com/komoot/photon

## 캠핑장명으로 찾아서 입력

기록 추가/수정에서 캠핑장 이름을 입력하고 **캠핑장 찾기**를 누르세요. 검색창에서 명칭 또는 지역+명칭을 직접 바꿔 재검색할 수 있습니다. 결과를 선택하면 이름·주소·구글 지도 검색 링크가 입력되고, 보유 위치값이 있는 곳은 지도에도 바로 표시됩니다. 위치값이 없는 결과는 지도에서 위치를 확인해 선택합니다. 결과가 없으면 **직접 찾아 입력하기**에서 구글 지도 명칭 검색, 직접 주소·지도 링크 입력, 무료 주소 검색과 지도 위치 선택을 사용할 수 있습니다.

검색은 앱에 포함한 무료 공공데이터 5,965개 항목을 사용합니다. 이 중 위치값을 가진 항목은 2,539개이며, 데이터에 없는 신설/명칭 변경 시설은 수동 보완이 필요합니다. API 키·결제가 필요 없으며 캠핑장명 검색은 외부 서버로 전송하지 않습니다. 외부 지도 검색 버튼을 누르면 검색어가 해당 지도 서비스로 전송됩니다.

출처: 한국관광공사 전국 야영장 등록 현황(2026-09-23), 한국문화정보원 전국 문화 여가 활동 시설(캠핑) 데이터(기준일 2022-11-30, 포털 정비본 2026-09). 두 자료 모두 이용허락범위 제한 없음. 과거 위치 자료는 이름·주소를 함께 대조해 최신 목록과 연결했고, 주소가 다른 결과에 이전 좌표를 붙이지 않았습니다. 데이터 기준일은 파일에 보관합니다. 지도 선택 시 최신 위치를 확인해주세요.

## 여러 기기 실시간 반영

기록·사진·화면 설정의 추가·수정·삭제는 서버 이벤트로 연결된 기기에 자동 반영됩니다. 편집·설정 창에서 작성 중인 내용은 유지하며 창을 닫거나 저장한 뒤 최신 내용을 받습니다. 끊긴 연결은 자동 재연결하고 화면 복귀/인터넷 재연결 시 최신 상태를 가져옵니다. 이벤트 전송을 막는 프록시·브라우저를 위한 15초 보완 확인도 적용됩니다. 기기별 사진 선택 방식은 각 기기의 설정을 유지합니다.

목록의 사진을 누르면 즉시 확대됩니다. 각 열 제목은 클릭할 때마다 오름차순 → 내림차순 → 기본 순서로 바뀝니다. 가격·사진 개수는 숫자로 정렬하고, 같은 값의 순서는 유지합니다. 기본 순서는 최근 등록한 기록부터입니다. 검색은 캠핑장명·플랫폼·주소·사이트명·메모를 포함합니다. 각 기기의 검색어·정렬 상태는 데이터 실시간 반영 중에도 유지됩니다.

예약 플랫폼은 선택 목록으로 제공합니다. 기본값은 홈페이지·캠핏·땡큐캠핑·네이버·캠핑톡입니다. **설정 → 예약 플랫폼 목록 → 이름 입력 → 추가 → 설정 저장**으로 새 플랫폼을 추가합니다. 추가한 값은 모든 기기에 반영되고 기존 기록의 플랫폼은 선택 목록에도 유지됩니다. 플랫폼 추가는 기존 플랫폼 목록을 삭제하지 않고 합쳐 저장합니다.

## 자체 앱 업데이트

안드로이드 앱 1.0.2 이상은 실행하거나 다시 화면으로 돌아올 때 최신 설치 파일을 확인합니다. 새 버전이 있으면 **업데이트 / 나중에** 알림이 표시됩니다. 업데이트를 누르면 다운로드·검증 후 Android 설치 화면으로 이어집니다. 처음에는 이 앱의 설치 허용을 요청할 수 있습니다. 패키지 이름·버전·해시·기존 서명을 확인하며 같은 앱 위에 설치하므로 기기 연결 정보는 유지됩니다. 작성 중이거나 사진을 선택·업로드하는 동안은 설치를 미룹니다. 기존 자동 확인이 없는 버전은 이번 설치 파일을 한 번 직접 설치한 뒤부터 자동 안내를 받을 수 있습니다.

아이폰 홈 화면 웹앱은 서버의 화면 버전을 확인하여 **업데이트** 안내를 표시합니다. 버튼을 누르면 새 화면으로 전환됩니다. 별도 앱스토어 설치 파일은 없으며 기록 변경은 화면 버전 업데이트와 별개로 실시간 동기화됩니다.

## 카카오 지도 연결
설정의 카카오 지도 연결에 JavaScript 키를 입력합니다. 카카오 개발자에서 지도 API를 활성화하고 JavaScript SDK 도메인에 `https://ha.badara.co.kr`을 등록해야 합니다. 내부 IP로 열 때는 해당 주소(포트 포함)도 등록해야 합니다. 키는 서버의 기존 설정에 저장되며 GitHub 소스에는 포함하지 않습니다. JavaScript 키는 브라우저에서 사용하는 공개 키이므로 등록 도메인 제한을 적용하세요.
연결 후 캠핑장 찾기는 카카오 장소 검색을 우선 사용하며, 선택 시 주소·지도 링크·좌표를 함께 입력합니다. 주소 검색도 카카오 좌표 조회와 연결됩니다. 기존 주소만 있는 기록은 수정 화면에서 지도 위치 선택을 눌러 좌표를 추가하세요. 카카오 키가 없으면 공공데이터 검색·구글 지도 열기를 사용할 수 있습니다.
사진 메모는 상세 화면 갤러리의 사진 아래에 입력하고 메모 저장을 누릅니다. 확대 화면에서는 해당 메모와 이전/다음 사진 버튼을 표시하며 좌우 스와이프·방향키도 지원합니다. 맨 위로 버튼은 240px 이상 스크롤 시 표시되고 설정에서 좌우 × 상·중·하 위치를 지정합니다.

안드로이드 앱 1.0.3은 새 APK가 있을 때 실행·복귀 시 알림을 표시합니다. 업데이트를 누르면 APK 다운로드·서명 검사를 거쳐 시스템 설치 화면을 열며, 마지막 설치 승인은 사용자가 눌러야 합니다. 화면 변경은 안드로이드에서 작성·사진 보기 종료 후 자동 적용합니다. 아이폰/브라우저에서는 화면 새로고침 알림으로 구분합니다. 초기 앱에서 APK 업데이트 알림이 없다면 앱 설치·연결에서 새 APK를 한 번 받아 설치하세요.
